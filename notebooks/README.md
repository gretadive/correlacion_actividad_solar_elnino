# Notebooks
Esta carpeta contiene los notebooks desarrollados en Google Colab para el preprocesamiento, 
análisis exploratorio, correlación de variables y aplicación de técnicas de aprendizaje automático sobre los datos de la tesis.
## Flujo de trabajo
- Limpieza y preparación de ICEN
- Limpieza y preparación de ONI
- Limpieza y preparación de SSN
- Integración de las variables
- Análisis exploratorio
- Análisis de correlación
- Aplicación de técnicas de aprendizaje automático
- Generación de gráficos y resultados
